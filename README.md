# LVDT-Based Displacement Measurement & Cloud Monitoring System

An ESP32-based displacement measurement system using an LVDT sensor, CAN bus communication, and cloud-based monitoring.

## Project Overview

This project demonstrates real-time displacement measurement using a Linear Variable Differential Transformer (LVDT) sensor and ESP32 microcontrollers.

The LVDT trainer generates an analog voltage corresponding to displacement. The ESP32 reads and processes the analog signal, and measurement data is communicated between ESP32 nodes using the CAN bus protocol.

The measured parameters can be monitored through a cloud-based dashboard, enabling remote observation of system measurements.

## System Architecture

- **LVDT Sensor:** Measures linear displacement.
- **ESP32:** Reads and processes the analog measurement signal.
- **CAN Bus:** Enables communication between ESP32 nodes.
- **Cloud Monitoring:** Supports remote visualization of measurement data.

## Technologies Used

- LVDT Displacement Sensor
- ESP32 Microcontroller
- MCP2515 CAN Controller Module
- Analog-to-Digital Conversion (ADC)
- CAN Bus Communication
- Embedded C/C++
- IoT and Cloud Monitoring

## Key Features

- LVDT-based displacement measurement
- Analog signal acquisition using ESP32
- CAN communication between two ESP32 nodes
- Real-time measurement data transmission
- Cloud-based monitoring of system parameters

## Applications

- Industrial displacement monitoring
- Machine condition monitoring
- Predictive maintenance systems
- Automotive and EV component monitoring
- Remote monitoring of measurement systems
